## Brand & Style

This design system defines the digital portfolio and personal engineering platform for a Full Stack Web Developer. It evokes precision, architectural discipline, and high-velocity craft. The emotional response is one of immediate technical credibility, modern sophistication, and immersive focus—reminiscent of high-performance developer environments, IDEs, and cutting-edge infrastructure dashboards.

The visual direction merges **Clean Developer Minimalism** with **Refined Dark Glassmorphism**:
- Deep slate and zinc environments provide high legibility for dense technical artifacts.
- Targeted emerald and cyan luminescence acts as telemetry feedback and focal anchors, avoiding cosmetic neon bloat.
- Muted indigo badges and micro-borders establish a multi-layered, structural architecture.
- Tactile code blocks, clean monospaced data tags, and subtle interactive glow states emulate real-time development tooling.

## Colors

The palette is engineered primarily for dark mode to minimize eye strain and elevate syntax clarity, with a structured light mode counterpart for high-ambient-light accessibility.

### Dark Mode (Default)
- **Canvas Base:** `#090D16` (Deep terminal zinc-black)
- **Surface Elevation 1 (Card/Container):** `#0F172A` with 70% opacity and subtle backdrop-blur
- **Surface Elevation 2 (Interactive/Overlay):** `#1E293B`
- **Primary Accent (`#10B981` Emerald):** Denotes active states, production readiness, interactive commit metrics, and primary calls to action.
- **Secondary Accent (`#06B6D4` Cyan):** Highlights endpoints, API parameters, live demo previews, and interactive tooltips.
- **Tertiary Accent (`#6366F1` Indigo):** Applied to runtime badges, language classifications, and experimental feature flags.
- **Text & Contrast:** 
  - Primary text: `#F8FAFC`
  - Secondary/Muted: `#94A3B8`
  - Borders/Dividers: `rgba(148, 163, 184, 0.12)`

### Light Mode Fallback
- **Canvas Base:** `#F8FAFC`
- **Surface Layer:** `#FFFFFF`
- **Surface Elevation:** `#F1F5F9`
- **Primary Accent:** `#059669` (Darkened emerald for WCAG AA compliance)
- **Secondary Accent:** `#0891B2`
- **Tertiary Accent:** `#4F46E5`
- **Text:** `#0F172A`

## Typography

The typography system relies on a dual-engine architecture:
- **Inter** handles high-legibility interface copy, structural headings, narrative descriptions, and modal content. Its tight tracking and neutral geometry anchor the system in contemporary web product standards.
- **JetBrains Mono** is deployed for technical telemetry, tech stack categories, micro-metadata, commit tags, inline syntax, and terminal views.

All display and large headline levels adopt negative tracking to maintain density and prevent visual fragmentation across wide displays. Code blocks must maintain strict horizontal alignment with tab stops set to 2 spaces.

## Layout & Spacing

The portfolio is structured on a 12-column fluid grid on desktop (`>1024px`) with a maximum container limit of `1280px` to maintain optimal viewing angles for project case studies and architectural flowcharts.

- **Desktop (1024px+):** 12 columns, `1.5rem` (24px) gutters, and `2rem` (32px) page margin padding.
- **Tablet (640px - 1023px):** 8 columns, `1.25rem` (20px) gutters, `1.5rem` (24px) margins.
- **Mobile (<640px):** 4 columns, `1rem` (16px) gutters, and `1rem` (16px) margins.

Internal component gaps follow the `space-*` scale. Asymmetrical offsets are discouraged; tech stack grids, project showcases, and credential sections must snap precisely to standard vertical increments (`space-sm` for dense list elements, `space-xl` for sectional breaks).

## Elevation & Depth

Visual hierarchy leverages a hybrid of **Tonal Layering** and **Subtle Glassmorphism** accented by low-intensity specular boundary lines:

1. **Base Layer:** `#090D16` pure matte canvas.
2. **Layer 1 (Cards, Code Sandboxes):** Background `rgba(15, 23, 42, 0.75)` with `12px` backdrop blur, bound by an ultra-thin perimeter stroke: `1px solid rgba(148, 163, 184, 0.08)`.
3. **Layer 2 (Hover & Focus States):** Card elevation is conveyed not through heavy drop shadows, but through localized luminous borders: `1px solid rgba(16, 185, 129, 0.35)` accompanied by a gentle ambient drop glow: `0 8px 30px -8px rgba(16, 185, 129, 0.12)`.
4. **Layer 3 (Modals & Overlays):** `#0F172A` with `95%` opacity, bounded by `1px solid rgba(6, 182, 212, 0.25)`, elevated above a `backdrop-filter: blur(8px)` dimming backdrop (`rgba(9, 13, 22, 0.8)`).

## Shapes

The design system implements a soft, engineered shape language (`roundedness: 1`):
- Standard interactive elements, form controls, and stack chips utilize `0.25rem` (4px) radii.
- Project cards, code sandboxes, and structural containers utilize `rounded-lg` (`0.5rem` / 8px).
- Modals, large feature callouts, and floating navigations scale up to `rounded-xl` (`0.75rem` / 12px).
- Full pills are strictly reserved for live status indicators (e.g., "Available for contract") and notification badges.

## Components

### Buttons
- **Primary:** High-emphasis solid emerald (`#10B981`) background, deep slate text (`#090D16`), weight `600`, font `Inter`. On hover: transition to `#34D399` with `box-shadow: 0 0 16px rgba(16, 185, 129, 0.35)`.
- **Secondary (Outline):** Transparent fill, `1px solid rgba(148, 163, 184, 0.2)`, text `#F8FAFC`. On hover: border switches to cyan (`#06B6D4`), surface tint `rgba(6, 182, 212, 0.05)`.
- **Icon / Terminal Button:** Monospaced label with trailing glyph, subtle background `#1E293B`, border `rgba(148, 163, 184, 0.1)`.

### Chips & Filters
- **Architecture/Filter Chips:** JetBrains Mono (`label-md`). Normal: `#1E293B` background, `#94A3B8` text, `0.25rem` radius. Active: Border `1px solid #10B981`, text `#10B981`, background `rgba(16, 185, 129, 0.08)`.
- **Badge / Category Chips:** Soft indigo (`rgba(99, 102, 241, 0.15)`) background with `#818CF8` text for architectural roles (e.g., `Backend`, `GraphQL`, `DevOps`).

### Cards & Project Showcases
- **Project Card:** Glass surface `rgba(15, 23, 42, 0.7)` with `12px` backdrop blur, `0.5rem` roundedness, `1px` border `rgba(148, 163, 184, 0.1)`. 
- **Hover Interaction:** Smooth transition (`200ms ease-out`): border shifts to `rgba(16, 185, 129, 0.4)`, slight 2px vertical lift, and subtle emerald glow. Tech stack icons render in monochrome `#94A3B8`, brightening to full accent color on card hover.

### Tech Stack Icons & Grid
- Tech items are encapsulated in individual square cells with a faint inner grid line (`border: 1px solid rgba(148, 163, 184, 0.08)`), pairing an SVG icon with a JetBrains Mono label underneath.

### Interactive Project Modals
- Fixed viewport center, max-width `840px`. Glassmorphic backdrop (`rgba(9, 13, 22, 0.85)` + `blur(8px)`).
- Top bar styled like an IDE title bar: file path label in `code-inline`, close toggle, and status indicators.
- Divided into multi-pane layout: live preview viewport, technical architecture breakdown, and performance/metric tags.

### Inputs & Terminal Fields
- Dark input fields (`#0B1120`), border `1px solid rgba(148, 163, 184, 0.15)`, text `#F8FAFC`, placeholder `#64748B`. Focused state: border `#06B6D4`, glow `0 0 0 1px #06B6D4`.
